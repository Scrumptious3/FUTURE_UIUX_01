# Luxury Beauty Salon Website UI/UX Design

## Project Overview
This project is a luxury salon website redesign created for a modern beauty business looking to improve its online presence and increase appointment bookings.

The goal was to create a premium, conversion-focused user experience that feels elegant, modern, and mobile-friendly.

---

## Problem Statement
Many local salons still rely on outdated websites or social media pages that:
- have poor navigation
- lack clear booking flows
- do not build trust with visitors
- fail to convert users into paying clients

---

## Solution
I designed a modern salon website experience that:
- clearly showcases services
- improves visual hierarchy
- encourages appointment bookings
- creates a premium luxury brand identity

---

## Features
- Responsive homepage design
- Clear service showcase
- Conversion-focused CTA sections
- Mobile-friendly layout
- Testimonials and trust sections
- Luxury dark-themed aesthetic

---

## Design Style
The interface uses a dark luxury visual identity featuring:
- Deep maroon backgrounds
- Elegant pink accents
- Soft contrast typography
- Modern card-based layouts
